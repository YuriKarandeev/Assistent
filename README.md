# Личный ассистент (PlanerOld)

Одностраничное PWA: календарь, канбан-проекты, чат с ИИ-ассистентом, синхронизация через Firebase.
Публикуется на GitHub Pages как статика (папка репозитория = корень сайта).

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение (разметка, стили, логика) |
| `ai.js` | ИИ-ассистент: ключ DeepSeek, контекст, разбор ответа, применение действий |
| `voice.js` | диктовка и озвучка (Web Speech API) |
| `sync-merge.js` | слияние состояния, надгробия, разрешение конфликтов |
| `sw.js` | service worker (кэш оболочки) |
| `manifest.webmanifest` | манифест PWA |
| `icons/` | иконки приложения |

## Обновление сайта

1. Правки делаются в рабочей папке проекта (`PlanerOld`), проверяются автотестами.
2. Содержимое копируется сюда без служебных файлов:

```powershell
robocopy 'S:\Разработка\Project1\PlanerOld' 'S:\Разработка\GitHub\Assistent' /E /XF '_*' '*.backup-*.html'
```

3. При изменении `index.html`, `ai.js` или `voice.js` поднять версию кэша в `sw.js`
   (`CACHE_NAME = 'assistant-planer-vN'`), иначе устройство останется на старой оболочке.
4. Закоммитить и отправить в `main` — GitHub Pages пересобирает сайт автоматически.

## Настройки, которые живут вне репозитория

- **Ключ DeepSeek** хранится только в `localStorage` устройства (слот `planer_deepseek_key`).
  На новом устройстве его нужно ввести заново: 💾 → «Ключ ИИ».
- **Авторизованные домены Firebase**: в консоли Firebase (Authentication → Settings →
  Authorized domains) должен быть добавлен домен вида `<логин>.github.io`, иначе вход
  через Google вернёт `auth/unauthorized-domain`.
- **Правила Firestore** публикуются в консоли Firebase (Firestore → Rules → Publish),
  файл `firestore.rules` лежит в рабочей папке проекта.

## Тестовый режим

Открыть сайт с `?sandbox=1` — данные пишутся в `users/{uid}/sandbox/main` и не затрагивают рабочий документ.
